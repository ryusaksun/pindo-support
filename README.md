# 拼豆码头 问题反馈

这里是 **拼豆码头** —— iOS 拼豆工具的问题反馈仓库，也放着它的[隐私政策](https://ryusaksun.github.io/pindo-support/privacy/)。

## 如何反馈

请通过 [Issues](https://github.com/ryusaksun/pindo-support/issues/new/choose) 提交，选「问题反馈」或「功能建议」，按表单填写。

识别不准的图纸，附上原图或小红书笔记链接最有帮助。

### 问题反馈要写的

- **哪一部分**：导入和识别图纸、图纸编辑、拼豆模式、库存、作品集、主屏幕小组件、我的
- **发生了什么**：遇到的问题，以及你原本期待的样子
- **怎么出现的**：按顺序写下操作步骤

### 可选（有助于更快定位问题）

- **截图、录屏或原图**
- **设备和系统**：iPhone 型号、iOS 版本
- **拼豆码头版本**：在「我的」→「关于」里查看
- **出现频率**：每次都会 / 偶尔出现 / 只出现过一次

这里公开可见，请不要填写手机号、邮箱、私人照片或其他敏感信息。

## Issue 标签说明

| 标签 | 含义 |
|------|------|
| `bug` | 已确认的问题 |
| `duplicate` | 重复提交 |
| `enhancement` | 功能建议 |
| `wontfix` | 暂不处理 |
